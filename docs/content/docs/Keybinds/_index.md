# Keybinds

This page conatins all keybinds used in AUrora. Keybinds are bascially keycombonation which does a certain task when you press the key combination

## Hyprland keybinds

| Keybind | Action |
| :-- | :-- |
| `SUPER + C` | Close current window |
| `SUPER + M` | Exit Hyprland |
| `SUPER + UP` | Move focus to upper window |
| `SUPER + DOWN` | Move focus to lower window |
| `SUPER + RIGHT` | Move focus to right window |
| `SUPER + LEFT` | Move focus to left window |
| `SUPER + V` | Toggle floating mode |
| `SUPER + P` | Toggle pseudo mode |
| `SUPER + S` | Open scratchpad workspace |
| `SUPER + SHIFT + S` | Move current window to scratchpad |
| `SUPER + SHIFT + RIGHT` | Resize window to the right |
| `SUPER + SHIFT + LEFT` | Resize window to the left |
| `SUPER + SHIFT + UP` | Resize window upward |
| `SUPER + SHIFT + DOWN` | Resize window downward |
| `SUPER + B` | Switch to dwindle layout |
| `SUPER + K` | Switch to master layout |
| `SUPER + X` | Switch to scrolling layout |
| `SUPER + Z` | Switch to monocle layout |
| `SUPER + J` | Toggle dwindle split |
| `SUPER + R` | Launch application launcher |
| `SUPER + ALT + Z` | Take screenshot |
| `SUPER + SPACE` | Switch keyboard layout |

## System keybinds

| Keybind | Action |
| :-- | :-- |
| `SUPER + L` | Lock the screen |
| `XF86AudioRaiseVolume` | Increase volume |
| `XF86AudioLowerVolume` | Decrease volume |
| `XF86AudioMute` | Mute audio |
| `XF86AudioMicMute` | Mute microphone |
| `XF86MonBrightnessUp` | Increase brightness |
| `XF86MonBrightnessDown` | Decrease brightness |
| `XF86AudioNext` | Next media track |
| `XF86AudioPlay` | Play media |
| `XF86AudioPause` | Pause media |
| `XF86AudioPrev` | Previous media track |

## Workspace keybinds

| Keybind | Action |
| :-- | :-- |
| `SUPER + [1-0]` | Switch workspace |
| `SUPER + SHIFT + [1-0]` | Move active window to workspace |
| `SUPER + Mouse Scroll Down` | Switch to next workspace |
| `SUPER + Mouse Scroll Up` | Switch to previous workspace |
